# 信车 PC · 资金渠道管理业务说明

> 所属模块：库容管理 > 资金渠道管理。本文只保留字段、权限、状态、校验和业务文案；公共布局、筛选、按钮、表格、表单、弹窗、抽屉和日志展示统一读取 [信车 PC 设计规范索引](../公共规范/INDEX.md)。

## 一、页面业务结构

- 页面无 Tab 分类栏，筛选条件区直接作为内容区首个业务区块。
- 页面顺序：新增渠道入口 → 筛选条件 → 数据表格 → 分页。
- 页面操作区与筛选区的间距、按钮尺寸和排列遵循公共布局及按钮规范。

## 二、筛选项与业务字段

| 筛选项 | 组件 | 业务规则 |
| --- | --- | --- |
| 市场名称 | 只读展示；超管可切换时使用 `el-select` | 普通用户自动显示当前市场；字段宽度 160px |
| 金融公司 | `el-select` | 含“全部”，选项为当前市场金融公司 |
| 渠道名称 | `el-input` | 模糊搜索，placeholder“请输入渠道名称” |
| 放款比例 | `el-input` | 按数值精确匹配 |
| 车辆评估方式 | `el-select` | 全部 / 自动评估 / 人工评估 |

筛选操作：查询、重置。查询触发检索，重置清空输入并恢复默认选项。

## 三、列表字段与操作映射

| 列名 | 业务展示 |
| --- | --- |
| 所属市场 | 纯文本 |
| 金融公司名称 | 纯文本 |
| 渠道名称 | 纯文本 |
| 放款比例 | 数值 + `%`，如 `80%` |
| 车辆评估方式 | 自动评估 / 人工评估 |
| 评估平台 | 多个平台以 `、` 间隔；人工评估显示 `—` |
| 创建时间 | `yyyy-MM-dd HH:mm:ss` |

操作集合由公共表格规范负责样式和权限过滤，本模块只定义业务映射：

| 操作 | 权限/条件 |
| --- | --- |
| 编辑 | 有编辑权限时展示；编辑态不可修改渠道名称、所属金融公司、放款比例等已锁定字段 |
| 删除 | 有删除权限时展示；删除前必须校验关联订单 |
| 操作日志 | 无权限限制，始终展示 |

空数据文案：`暂无资金渠道`，并提供“点击「+ 新增渠道」开始配置”引导。

## 四、新增 / 编辑资金渠道

### 4.1 字段规则

| 字段 | 业务规则 |
| --- | --- |
| 渠道名称 | 必填；最多 50 个字符；重复时提示“该渠道名称已存在，请更换”；编辑时不可修改 |
| 所属金融公司 | 必填；当前市场金融公司列表；编辑时不可修改；无数据时提示“当前市场暂无金融公司，请先前往金融公司管理完成配置” |
| 放款比例 | 必填；1～100，最多两位小数；超范围提示“放款比例须在 1% ～ 100% 之间” |
| 车辆评估方式 | 必填；自动评估 / 人工评估；存在进行中关联订单时不可修改 |
| 评估平台 | 自动评估时必填，可多选；人工评估时隐藏；接口异常提示“评估平台数据加载失败，请刷新页面重试” |

### 4.2 提交行为

- 保存前执行全字段校验，提交中按钮进入 `loading`，防止重复提交。
- 保存成功后关闭弹窗并刷新列表。
- 取消关闭弹窗且不保存。

## 五、删除业务校验

- 删除前先校验是否存在关联订单。
- 存在关联订单：不打开确认弹窗，直接展示拦截提示“该资金渠道已有关联订单，无法删除。”
- 无关联订单：使用公共弹窗规范的简洁确认款，文案为“确定要删除吗？”。

## 六、操作日志业务字段

展示方式统一采用公共弹窗与抽屉规范的表格方案，按时间倒序排列。业务字段：

| 字段 | 内容 |
| --- | --- |
| 操作类型 | 新增 / 编辑 / 删除 |
| 操作人 | 操作人姓名 |
| 操作时间 | `yyyy-MM-dd HH:mm:ss` |
| 变更内容 | 编辑时展示“字段名：旧值 → 新值” |

## 七、权限口径

| 场景 | 业务规则 |
| --- | --- |
| 无新增权限 | 不展示“+ 新增渠道” |
| 无编辑权限 | 不展示“编辑” |
| 无删除权限 | 不展示“删除” |
| 操作日志 | 始终展示 |

## 八、关联改动：市场配置金融订单编号前缀

字段位于市场配置 → 金融系统设置模块，紧跟“金融系统”开关下方。

| 校验项 | 提示文案 |
| --- | --- |
| 必填（开启金融系统时） | 请输入金融订单编号前缀 |
| 格式（仅大写字母 A-Z） | 编号前缀仅支持大写字母（A-Z） |
| 长度（2～6 位） | 编号前缀长度须在 2～6 位之间 |
| 唯一性 | 该编号前缀已被其他市场使用，请更换 |

已产生金融订单后，字段使用公共表单规范的禁用态，并提示“已有金融订单，编号前缀不可修改”。
