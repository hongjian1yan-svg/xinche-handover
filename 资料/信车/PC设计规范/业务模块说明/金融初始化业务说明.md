# 信车 PC · 金融初始化业务说明

> 所属模块：库容管理 > 金融初始化。本文只保留金融公司与资金渠道的字段、权限、状态和业务联动；公共布局、筛选、按钮、表格、表单、弹窗、抽屉和日志展示统一读取 [信车 PC 设计规范索引](../公共规范/INDEX.md)。

<!-- #AI:design:start -->
## 一、页面业务结构

- 页面无 Tab 分类栏，由两个独立业务模块上下排列：金融公司在上，资金渠道在下。
- 模块标题、模块间距和多模块页面骨架遵循公共页面整体布局规范。
- 两个模块不共用筛选条件和操作按钮；业务联动仅按本说明执行。

## 二、金融公司模块

### 2.1 筛选字段

| 筛选项 | 业务规则 |
| --- | --- |
| 市场名称 | 超管可选所有市场；市场管理员固定显示本市场 |
| 金融公司 | 模糊搜索，placeholder“请输入金融公司名称” |
| 负责人 | 模糊搜索，placeholder“请输入负责人” |
| 负责人电话 | 按电话字段筛选 |
| 创建时间 | 日期范围筛选 |

操作：查询、重置、查询数据导出。

### 2.2 列表字段与操作

| 列名 | 业务展示 |
| --- | --- |
| 所属市场 | 纯文本 |
| 金融公司名称 | 纯文本 |
| 负责人 | 纯文本 |
| 负责人电话 | 纯文本 |
| 负责人证件号 | 可为空，显示 `—` |
| 资金渠道数量 | 实时统计该公司下渠道数，0 直接显示 `0` |
| 创建时间 | `yyyy-MM-dd HH:mm:ss` |

| 操作 | 权限/位置 |
| --- | --- |
| 查看 | 无权限限制，直接显示 |
| 编辑 | 有编辑权限时展示，位于更多操作内 |
| 删除 | 有删除权限时展示，位于更多操作内 |

### 2.3 新增 / 编辑金融公司

| 字段 | 业务规则 |
| --- | --- |
| 所属市场 | 必填；超管可选所有市场；市场管理员只读本市场 |
| 公司名称 | 必填；placeholder“请输入公司名称” |
| 负责人 | 必填；placeholder“请输入负责人” |
| 负责人电话 | 必填；手机号格式校验 |
| 证件号码 | 非必填 |
| 备注 | 非必填；最多 50 字 |
| 图片信息 | 非必填；最多上传一张图片 |

新增时提供“继续新增资金渠道”：金融公司保存成功后关闭当前弹窗，打开新增资金渠道弹窗，并自动预填所属市场和所属金融公司且禁止修改。

## 三、金融公司详情业务内容

详情采用公共右侧抽屉规范；本模块只定义内容：

- 基本信息：所属市场、创建时间、操作人。
- 金融公司信息：公司名称、负责人、负责人电话、负责人证件号、备注。
- 图片信息：无图片时使用公共空态。
- 资金渠道只读列表：渠道名称、放款比例、车辆评估方式、评估平台、创建时间。
- 无资金渠道时显示“暂无资金渠道”，不展示操作按钮。

## 四、资金渠道模块

### 4.1 筛选字段

| 筛选项 | 业务规则 |
| --- | --- |
| 市场名称 | 超管可选所有市场；市场管理员固定显示本市场 |
| 金融公司 | 当前市场金融公司列表，含“全部” |
| 渠道名称 | 模糊搜索 |
| 车辆评估方式 | 全部 / 自动评估 / 人工评估 |
| 放款比例 | 数值筛选 |

### 4.2 列表字段与操作

| 列名 | 业务展示 |
| --- | --- |
| 所属市场 | 纯文本 |
| 金融公司名称 | 纯文本 |
| 渠道名称 | 纯文本 |
| 放款比例 | 数值 + `%` |
| 车辆评估方式 | 自动评估 / 人工评估 |
| 评估平台 | 多个平台以 `、` 间隔；人工评估显示 `—` |
| 渠道说明 | 为空显示 `—`；长文案按公共表格规则处理 |
| 创建时间 | `yyyy-MM-dd HH:mm:ss` |

| 操作 | 权限/条件 |
| --- | --- |
| 编辑 | 有编辑权限时展示 |
| 删除 | 有删除权限时展示，删除前校验进行中的质押订单 |
| 操作日志 | 无权限限制，始终展示 |

无渠道数据时显示：`暂无资金渠道，点击「+ 新增渠道」开始配置`。

### 4.3 新增 / 编辑资金渠道

| 字段 | 业务规则 |
| --- | --- |
| 所属市场 | 仅超管显示；新增/编辑可选所有市场；市场管理员默认归属本市场 |
| 渠道名称 | 必填；最多 50 字；重复提示“该渠道名称已存在，请更换” |
| 所属金融公司 | 必填；当前市场金融公司列表；无数据时提示先完成金融公司配置 |
| 放款比例 | 必填；1～100，最多两位小数 |
| 车辆评估方式 | 必填；自动评估 / 人工评估 |
| 评估平台 | 自动评估时必填、多选；人工评估时隐藏；接口异常提示刷新页面 |
| 渠道说明 | 非必填；最多 100 字 |

市场核价自动评估开关关闭时：自动评估选项置灰，弹窗打开时强制选中人工评估；点击置灰选项提示“暂未开启自动评估，请联系管理员”。

## 五、删除业务校验

| 对象 | 校验与提示 |
| --- | --- |
| 金融公司 | 存在关联资金渠道时不可删除，提示“该金融公司下存在资金渠道，请先删除相关渠道后再操作。” |
| 资金渠道 | 存在进行中的质押订单时不可删除，提示“该资金渠道存在进行中的质押订单，无法删除。” |

校验通过后分别使用公共弹窗规范的完整卡片款（金融公司）或简洁款（资金渠道）。

## 六、操作日志业务字段

展示方式统一采用公共弹窗与抽屉规范的表格方案，按时间倒序排列。字段包括：操作类型、操作人、操作时间、变更内容（编辑时展示旧值 → 新值）。

## 七、权限口径

无新增、编辑、删除权限时，不渲染对应按钮；查看和操作日志无权限限制。具体视觉表现遵循公共按钮、表格规范。

## 八、关联改动：市场配置

### 8.1 金融订单编号前缀

字段位于市场配置 → 金融系统设置模块，紧跟“金融系统”开关下方。

| 校验项 | 提示文案 |
| --- | --- |
| 必填 | 请输入金融订单编号前缀 |
| 格式（仅大写字母 A-Z） | 编号前缀仅支持大写字母（A-Z） |
| 长度（2～6 位） | 编号前缀长度须在 2～6 位之间 |
| 唯一性 | 该编号前缀已被其他市场使用，请更换 |

已产生金融订单后，字段使用公共表单规范的禁用态，并提示“已有金融订单，编号前缀不可修改”。

### 8.2 市场核价自动评估开关

位置：市场配置 → 金融系统设置模块 → 金融订单编号前缀下方。组件为 `el-switch`，默认关闭。开启后，资金渠道配置中才允许选择自动评估方式。
