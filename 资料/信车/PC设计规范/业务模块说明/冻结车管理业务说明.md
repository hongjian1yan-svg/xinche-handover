# 冻结车管理业务说明

> 适用范围：冻结车管理二期（`冻结车管理.html`）。本文只保留冻结车业务字段、状态、枚举和操作映射；通用 Tab、表格、标签、表单、弹窗、抽屉和布局规则统一读取 [信车 PC 设计规范索引](../公共规范/INDEX.md)。

## 一、业务状态与 Tab

冻结车列表使用公共 Tab 组件的自定义 Tab 变体，业务枚举如下：

| Tab | 业务含义 |
| --- | --- |
| 已冻结 | 当前处于冻结状态的车辆 |
| 已解冻 | 已完成解冻的车辆 |
| 待审核 | 等待冻结申请审核的车辆 |
| 审核通过 | 审核通过但尚未进入最终冻结状态的车辆 |
| 审核驳回 | 审核未通过的车辆 |

## 二、冻结来源与筛选联动

| 冻结来源 | 标签文字 |
| --- | --- |
| 手动冻结 | 手动冻结 |
| 金融质押冻结 | 金融质押冻结 |
| 合同到期冻结 | 合同到期冻结 |
| 金融管控冻结 | 金融管控冻结 |

冻结来源筛选变化时，按公共 Tab 联动规则重新计算可见 Tab；业务映射如下：

| 冻结来源筛选值 | 展示 Tab |
| --- | --- |
| 全部（未选择） | 已冻结 / 已解冻 / 待审核 / 审核通过 / 审核驳回 |
| 手动冻结 | 已冻结 / 已解冻 / 待审核 / 审核通过 / 审核驳回 |
| 金融质押冻结 | 已冻结 / 已解冻 |
| 合同到期冻结 | 已冻结 / 已解冻 |
| 金融管控冻结 | 已冻结 / 已解冻 |

## 三、业务操作映射

操作按钮样式、尺寸、排列和权限显隐统一读取公共表格与按钮规范；本节只定义“状态 → 操作集合”：

| Tab | 操作列按钮 |
| --- | --- |
| 已冻结 | 查看详情 / 车辆解冻（按来源与角色权限判断）/ 操作日志 |
| 已解冻 | 查看详情 / 操作日志 |
| 待审核 | 查看详情 / 审核通过 / 审核驳回 / 操作日志 |
| 审核通过、审核驳回 | 查看详情 / 操作日志 |

## 四、详情业务内容

- 详情使用公共右侧抽屉和 Section 标题规范。
- 车辆信息使用 `el-descriptions`，两列展示；冻结照片无数据时使用公共空态。
- 详情中展示冻结来源、车牌号和生命周期状态标签，标签视觉统一读取公共标签规范。
