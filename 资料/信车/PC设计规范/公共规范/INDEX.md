## 1. 适用范围与优先级

本目录适用于信车 PC 管理后台的页面、浏览器原型和生产开发交接。PC 生产技术栈固定为 **Vue 2 + ElementUI 2.15.14 + JavaScript**；不使用 Vue 3、Element Plus 或 TypeScript。

统一布局基线：顶部状态栏固定 **60px**；各业务子模块规范不得另行覆盖。侧边栏 Logo 区与顶部状态栏同为 **60px**。

规则优先级：

1. YAN 本次明确确认的需求、Figma 旁注和验收结论。
2. 目标模块的业务说明（仅对该模块生效）。
3. 本目录的公共组件规范。
4. `xinche-pc/AGENTS.md` 与工作区 `AGENTS.md` 的交付、验证和权限规则。

专用规范与公共规范冲突时，不静默猜测：保留业务专用规则，并把技术栈或视觉差异标为“待确认”；涉及通用组件的差异应回写公共规范或明确为模块变体。

## 6. Agent 最小读取路径

- 普通 PC 列表：本索引 → 全局视觉 → 页面整体布局 → 表格 → 按钮/表单/Tab（按页面实际使用选择）。
- 详情抽屉或弹窗：本索引 → 全局视觉 → 页面整体布局 → 弹窗与抽屉 → 表格/标签（按实际使用选择）。
- 冻结车、资金渠道或金融初始化：本索引 → 对应业务说明 → 需要的公共组件规范；发现技术栈冲突时以 `AGENTS.md` 和本索引的冲突记录为准，不直接复制旧写法。
- 鸿源市场官网：只读官网目录下的专用规范与 PRD，不读取本目录的后台页面规范。
