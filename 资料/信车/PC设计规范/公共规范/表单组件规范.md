# 表单组件规范 (Form Components)

## 一、 表单基础 (Form)

*   **规范定义**：用于组织数据输入项，承载信息的收集与提交逻辑。
*   **视觉参数**：
    *   **Label 对齐**：优先推荐 **右对齐**（Label 宽度建议 **80px - 120px**），在长表单或多语言环境下可使用 **顶部对齐**。
    *   **弹窗 / 多行控件**：标签与控件区域采用 **顶部对齐**（`align-items: start`），不得相对整块内容垂直居中。适用于控件下方有说明文案、开关+搜索、上传区等增高模块。
    *   **必填项星号 (*)**：固定位于 Label 左侧，颜色使用 **#F56C6C**，与文字间距 **4px**。
    *   **表单项垂直间距**：默认 **22px**（包含错误校验提示空间）。
    *   **标签宽度**：筛选区默认 `80px`；弹窗表单默认 `80–100px`。字段较长时可由页面业务说明明确调整，但同一表单内必须统一。
    *   **筛选控件高度**：输入框、选择框、日期选择器及查询/重置按钮默认 `40px`，对应 ElementUI 默认尺寸。
*   **交互规则**：支持单列布局（表单流向下）或双列布局（高密度信息）。
*   **权限规则**：无字段权限时不渲染字段；有字段查看权限但无编辑权限时，使用只读展示或 `disabled`，不得伪装成可编辑控件。
*   **使用场景**：后台管理系统的数据编辑、筛选、设置页面。
*   **Design Skill**：
    *   **逻辑分组**：针对长表单，应使用 `Card` 组件或 `Divider` 进行逻辑分组，并为每组提供明确的标题。
    *   **锚点定位**：超过 3 组以上的长表单，建议在右侧或左侧配置 **Anchor (锚点)** 导航，支持点击跳转至对应分组。

## 二、 输入框 (Input)

*   **规范定义**：基础文本输入组件。
*   **视觉参数**：
    *   **尺寸与字体**：
        *   **Large (40px)**：字号 **16px**，适用于搜索页核心输入。
        *   **Default (32px)**：字号 **14px**，通用场景（最推荐）。
        *   **Small (24px)**：字号 **12px**，适用于紧凑表格行内编辑。
    *   **圆角**：**4px**。
    *   **默认边框**：**#DCDFE6**。
*   **交互规则**：
    *   **Hover**：边框色变为 **#C0C4CC**。
    *   **Focus**：边框色变为 **#409EFF**，并增加淡蓝色外阴影。
    *   **Readonly**：背景色 **#F5F7FA**，边框颜色不变，文字可选中但不可编辑。
    *   **Disabled**：背景色 **#F5F7FA**，文字色 **#C0C4CC**，光标显示 `not-allowed`。
*   **校验反馈**：
    *   **校验失败**：边框色切换为 **#F56C6C**。
    *   **提示位置**：错误文案（12px）显示在输入框下方，距离输入框底部 **4px**。
*   **使用场景**：账号登录、信息备注、数值录入。

## 三、 只读展示字段

筛选区或表单中需要展示不可编辑的市场、组织等信息时，优先使用只读文本，不伪装成可输入控件。默认保持 `40px` 高度、左右 `12px` 内边距、`#F5F7FA` 背景、`1px solid #DCDFE6` 边框和 `4px` 圆角；字段宽度由模块字段表确认。

<!-- #AI:design:start -->
### 只读与禁用的选用

* 仅展示、不参与提交的字段：使用只读展示字段。
* 仍属于表单模型、但当前业务状态不可修改的字段：保留控件并使用 `disabled`。
* 编辑态和新增态的字段差异，应由页面业务说明或 PRD 定义；公共规范只约束视觉和交互表现。

## 四、 下拉选择 (Select)

*   **规范定义**：从预设列表中选择一个或多个值。
*   **视觉参数**：
    *   **尺寸**：对齐 Input 组件（弹窗内常用高度 **40px**）。
    *   **边框**：与 Input **完全一致**——默认 `#DCDFE6`，Hover `#C0C4CC`，Focus/展开 `#409EFF`（可加 `0 0 0 2px #ECF5FF`）；圆角 **4px**。禁止使用与 Input 不同的 inset `box-shadow` 描边，避免筛选区、弹窗内选择框与输入框边框观感不一致。
    *   **下拉面板**：最大展开高度建议为 **250px - 300px**，超出则出现滚动条。
<!-- #AI:design:start -->
    *   **默认与选中值**：触发器未选择时占位文字为 **#C0C4CC**；选中值为 **#606266**；字号 **14px**，在 **40px** 控件内垂直居中。默认边框沿用 Input 的 **#DCDFE6** 与 **4px** 圆角。
    *   **触发器交互**：悬停边框使用 **#C0C4CC**；聚焦或展开边框使用 **#409EFF**，并显示 **0 0 0 2px #ECF5FF** 柔和外阴影。右侧垂直居中显示 ElementUI 下箭头，默认颜色 **#C0C4CC**，展开时随状态旋转并体现主色焦点。
    *   **选项浮层**：白底 **#FFFFFF**、边框 **#E4E7ED**、圆角 **4px**、阴影 **0 2px 12px rgba(0, 0, 0, .1)**；最大内容高度 **274px**，超出后在面板内滚动。浮层须显示在筛选区和表格内容上方，不得被容器裁切或遮挡。
    *   **选项行**：默认白底、文字 **#606266**，行高 **34px**、水平内边距 **20px**；悬停行背景 **#F5F7FA**。选中项背景 **#F5F7FA**、文字 **#409EFF**、字重 **700**。
    *   **面板实现**：使用 ElementUI `el-select` 或与其视觉和交互一致的自绘选项浮层；不得打开浏览器或操作系统原生下拉面板。原型可保留隐藏的原生 select 作为原有筛选值载体，但用户操作必须由自绘浮层完成。
<!-- #AI:design:end -->
*   **交互规则**：
    *   **下箭头**：所有下拉选择框（筛选项、表单项、弹窗项）右侧必须显示下箭头；仅单选/复选分段按钮、日期选择器等非下拉控件除外。
    *   **点击外部收起**：点击触发器与下拉面板以外区域须收起面板。
    *   **滚动条样式**：宽度 **6px**，圆角 **4px**，轨道透明，滑块颜色 **#C0C4CC**，悬停滑块 **#909399**。
    *   **选中态**：下拉项背景色为 **#F5F7FA**，文字颜色为 **#409EFF** 且加粗。
*   **Design Skill**：
    *   **模糊搜索**：当选项超过 10 条时，必须开启可搜索功能 (`filterable`)。
    *   **空状态**：当搜索无结果时，下拉框应显示“暂无匹配数据”图文说明。

## 五、 单选/复选 (Radio/Checkbox)

*   **规范定义**：用于在多个互斥或并列选项中进行选择。
*   **视觉参数**：
    *   **图标尺寸**：标准 14px × 14px。
    *   **选中色值**：背景/边框使用 **#409EFF**。
    *   **间距**：选项间距建议 **16px - 24px**。
*   **交互规则**：
    *   **点击区域**：支持点击文字触发选中，增加易用性。
    *   **Indeterminate (半选)**：在多级复选树中，子项未全选时父项显示“减号”图标。
*   **禁用场景**：业务逻辑冲突或当前用户无权限操作。

## 六、 分段按钮 (Segmented)

*   **规范定义**：一组互斥选项横向连成一条，选中项整段填充主色，用于选项少、文案短、需一眼扫完的互斥选择。不是下拉，也不是独立 Radio 圆点。
*   **与 Radio / Select 的选用**：

| 控件 | 适用 |
| --- | --- |
| 分段按钮 | 2～5 个短文案互斥项（如开/关、不限制/限制、抵扣/折扣）；选项固定、不需搜索 |
| Radio | 选项较长、需换行说明，或与其它表单项混排时 |
| Select | 选项超过 5 个，或需要搜索、远程加载 |

*   **视觉参数**：
    *   **高度**：弹窗与筛选区内 **40px**，与 Large Input 对齐。
    *   **单项最小宽度**：约 **70px**；文案短时可 `padding: 0 20px～24px`。
    *   **字号**：14px；未选文字 **#606266**；未选背景 **#FFFFFF**；未选边框 **#DCDFE6**。
    *   **选中态**：背景与边框 **#409EFF**，文字白色；`z-index` 高于相邻项，避免双边框叠色。
    *   **圆角**：整组左端 `4px 0 0 4px`、右端 `0 4px 4px 0`；中间项无外圆角。相邻项共用 1px 边框（后项 `margin-left: -1px`）。
*   **交互规则**：
    *   同一组同时仅一项选中；点击即切换，无需确认。
    *   只读/禁用：整组降低透明度并禁止点击（与编辑弹窗只读字段一致）。
    *   **不显示下拉箭头**（见第三节例外）。
*   **组合**：常与右侧输入框、日期范围并排（左分段、右条件控件）；未选「限制」类选项时隐藏右侧控件。

```css
.segmented {
  display: flex;
}
.segmented button {
  height: 40px;
  min-width: 70px;
  padding: 0 24px;
  border: 1px solid #dcdfe6;
  background: #fff;
  color: #606266;
  font-size: 14px;
  cursor: pointer;
}
.segmented button + button {
  margin-left: -1px;
}
.segmented button:first-child {
  border-radius: 4px 0 0 4px;
}
.segmented button:last-child {
  border-radius: 0 4px 4px 0;
}
.segmented button.active {
  position: relative;
  z-index: 1;
  border-color: #409eff;
  background: #409eff;
  color: #fff;
}
```

## 七、 日期选择器 (DatePicker)

*   **规范定义**：用于选择特定日期、时间点或时间范围。
*   **视觉参数**：
    *   **面板尺寸**：单日面板宽度约 **280px**，范围面板宽度约 **560px**。
    *   **高亮色**：选中日期/起始日期背景为 **#409EFF**，范围区间背景为 **#ECF5FF**（主色 10% 透明度）。
*   **交互规则**：
    *   **快捷选项**：左侧或顶部建议提供“最近一周”、“最近一月”、“今天”等快捷入口。
    *   **不可选状态**：过去日期或未来日期（视业务逻辑而定）需置灰并禁用点击。
*   **示例说明**：范围选择器内包含两个日期，中间通过“至”或“ - ”连接。

## 八、 Design Skill (交互进阶)

### 1. 反馈及时性
*   **实时校验**：针对格式要求严格的字段（如手机号、邮箱），应在 `Blur`（失去焦点）时立即触发校验，而非等到点击提交。

### 2. 占位符 (Placeholder)
*   占位文字颜色统一为 **#C0C4CC**。
*   文案应具有引导性：输入框使用“请输入XXX”，下拉框使用“请选择XXX”。

### 3. 操作按钮位置
*   表单底部的操作组（提交/取消）应固定在页面底部或表单末尾，且主按钮（Primary）位于左侧（跟随视觉流）。
