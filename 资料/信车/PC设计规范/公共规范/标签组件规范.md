## 一、 来源标签（Source Tag）

### 使用场景
* 表格中的来源/渠道/业务类型列
* 详情摘要卡片中，名称或主标识下方

### 视觉参数
* **文字颜色**：`#F56C6C`（系统危险色，统一警示红）
* **背景色**：`#fef0f0`
* **边框**：`1px solid #fbc4c4`
* **圆角**：`3px`
* **内边距**：`2px 8px`
* **字号**：`12px`，字重 `500`

### 标签文案
页面业务说明负责提供实际来源类型和展示文案；同一模块内来源标签统一使用本节样式。

> 同一模块的来源类型统一使用同一颜色，通过文字区分，不做颜色差异化处理。

### CSS 实现
```css
.source-tag {
  display: inline-block;
  color: #F56C6C;
  font-size: 12px;
  font-weight: 500;
  background: #fef0f0;
  border: 1px solid #fbc4c4;
  padding: 2px 8px;
  border-radius: 3px;
}
```

### Vue 使用示例
```html
<span class="source-tag">{{ SOURCE_MAP[row.source] }}</span>
```

## 二、 车牌号标签（Plate Tag）

### 使用场景
* 表格「车牌号」列
* 详情抽屉车辆基本信息卡片中

### 视觉参数
* **文字颜色**：`#303133`
* **背景色**：`#f4f4f5`
* **边框**：`1px solid #e9e9eb`
* **圆角**：`3px`
* **内边距**：`2px 8px`
* **字号**：`13px`
* **字体**：`monospace`（等宽字体，便于识别字符）

### CSS 实现
```css
.plate-tag {
  display: inline-block;
  background: #f4f4f5;
  border: 1px solid #e9e9eb;
  padding: 2px 8px;
  border-radius: 3px;
  font-size: 13px;
  color: #303133;
  font-family: monospace;
}
```

## 三、 业务状态标签（Status Tag）

用于列表「状态」列、详情标题旁的**生命周期状态**（在架 / 下架、启用 / 停用、通过 / 驳回等）。来源类属性一律使用第一节来源标签，不按生命周期状态换色；状态类才用本节绿 / 红（及中性）。

### 视觉参数（轻量 Tag，对齐 Element `effect="light"`）

| 语义 | 文字色 | 背景 | 边框 | 典型含义 |
| --- | --- | --- | --- | --- |
| 正向 / 生效 | `#67C23A` | `#f0f9eb` | `1px solid #b3e19d` | 已上架、已启用、已通过 |
| 否定 / 失效 | `#F56C6C` | `#fef0f0` | `1px solid #fbc4c4` | 已下架、已停用、已驳回 |
| 中性 / 等待 | `#909399` | `#f4f4f5` | `1px solid #e9e9eb` | 待处理、草稿（无既定成功/失败语义时） |

* **圆角**：`3px`
* **内边距**：`2px 8px`（详情标题旁可用 `3px 8px`）
* **字号**：列表 `12px`；详情旁可读 `13px`；字重 `400`（不加粗）
* **实现**：优先 `el-tag` + `type="success" | "danger" | "info"` + `effect="light"` + `size="small"`；静态预览可用同等色值的 `<span>`。

```css
.status-tag {
  display: inline-block;
  padding: 2px 8px;
  border-radius: 3px;
  font-size: 12px;
  font-weight: 400;
  line-height: 1.4;
}
.status-tag--success {
  color: #67c23a;
  background: #f0f9eb;
  border: 1px solid #b3e19d;
}
.status-tag--danger {
  color: #f56c6c;
  background: #fef0f0;
  border: 1px solid #fbc4c4;
}
.status-tag--info {
  color: #909399;
  background: #f4f4f5;
  border: 1px solid #e9e9eb;
}
```

```html
<el-tag type="success" effect="light" size="small">已上架</el-tag>
<el-tag type="danger" effect="light" size="small">已下架</el-tag>
```

> 同一模块列表与详情必须用同一套状态色；禁止把失效状态做成绿色，也禁止用来源标签代替状态 Tag。

## 四、 与 el-tag 的选用原则

| 场景 | 推荐方案 |
|-----|--------|
| 表格单元格内的属性标注（来源、车牌） | 自定义 `<span>` + CSS（轻量，无多余样式） |
| 业务生命周期状态（上架/下架、启用/停用等） | 本节状态 Tag，或同等色值的 `el-tag` light |
| 其它状态标注（已审核、待处理等） | `el-tag`（带 `type` 属性，语义清晰） |
| 详情页信息展示 | 两者均可，优先与列表保持一致 |
