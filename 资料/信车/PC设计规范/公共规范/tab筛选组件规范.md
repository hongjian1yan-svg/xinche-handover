# PC端UI设计规范（列表过滤组件）

## 1. 顶部 Tab 分类（Tabs）
用于切换不同业务状态下的数据列表。

### 视觉参数
* **组件样式**：采用矩形色块选项卡。
* **尺寸**：每个 Tab 宽度 **90px**，高度 **40px**。
* **状态设置**：
    * 具体 Tab 枚举由页面业务说明或已确认 PRD 定义，公共规范不预设业务状态名称。
* **背景色**：
    * 非激活状态：浅灰色背景 `#f9fafb`。
    * 激活状态：浅灰色背景 **#F2F2F2**。
* **文字颜色**：均为 **#303133**（14px）。
* **边框**：每个 Tab 带有除底部外的 `1px` 实线边框，颜色为 **#e3e4e5**。

<!-- #AI:design:start -->
### 自定义 Tab 变体

业务状态需要横向快速切换、且不适合使用 `el-tabs` 时，可使用自定义 `.tab-item` 变体：宽度 **90px**、高度 **40px**；未激活背景 `#f9fafb`，激活背景 `#f2f2f2`，Hover 背景 `#ecf5ff`、文字 `#409eff`。变体仍须遵循本规范的 Tab 联动和分页回退规则。

## 2. 筛选项容器（Filter Container）
承载复杂的搜索条件，采用 **多行表单布局**。

### 布局规范
* **布局**：多行表单布局，距离主内容容器上下 20px，左右 12px。
* **容器边距**：内容距背景上下 **20px**，左右 **12px**；**左对齐展示**。
* **间距**：与上方 Tab 区域无间距，无需分割线。
* **背景色**：矩形背景色 **#F2F2F2**。
* **下方内容间距**：距离下方表格内容 **40px**。
<!-- #AI:design:start -->
* **筛选项间距**：筛选项横向、纵向间距固定为 **16px**；不得因列宽或换行状态改变相邻筛选项间距。
* **筛选控件宽度**：短文案输入框或选择框默认使用 **180px** 实际宽度；需要展示较长默认值、完整提示或日期范围的控件按内容适当加宽。不同字段允许使用不同宽度，不得强制所有控件等宽，也不得只设最小宽度后被网格拉伸。
<!-- #AI:design:end -->
* **操作按钮布局**：
    * **位置**：强制在筛选项内容的第二行（或最末行）单独展示。
    * **对齐**：整体左对齐，起始位置需设置 **92px** 的左边距（计算逻辑：80px 标签宽度 + 12px 固定间距）。
    * **间距**：按钮水平间隔 **12px**。
    <!-- #AI:design:start -->
    * **按钮行上间距**：筛选字段区域与独立按钮行之间固定保持 **16px** 垂直间距。
    * **按钮行底部留白**：操作按钮项底部外边距（margin-bottom）设为 **0**；筛选面板保留 **20px** 底部内边距，按钮底缘至面板内边界保持 **20px**。
    <!-- #AI:design:end -->

### 元素规范
* **表单项结构**：水平布局（Inline-flex）。
    * **Label 宽度**：统一设为 **80px**，文字右对齐，距控件固定 **12px**。
    * **控件高度**：输入框、选择框及查询/重置按钮统一为 **40px**（ElementUI 默认尺寸，不传 `size`）。
* **控件类型**：
    * **输入框 (Input)**：车牌号、商户名称、车架号、RFID。
    * **选择框 (Select)**：所属市场、业务状态、来源类型、分类、是否评估等已确认枚举。
    * **日期选择 (Date Picker)**：时间区间（datetimerange）。
<!-- #AI:design:start -->
### 筛选控件默认态文字

* **输入框**：未输入时显示「请输入 + 字段名」的引导文字，颜色 **#C0C4CC**；输入值使用 **#606266**。
* **选择框**：未选择时显示「请选择 + 字段名」，颜色 **#C0C4CC**；选中值使用 **#606266**。右侧下拉箭头使用 ElementUI 图标，颜色 **#C0C4CC**，垂直居中。
* **日期范围**：起止控件分别显示「开始日期」「结束日期」，中间使用「至」；日期图标使用 ElementUI `el-icon-date`，颜色 **#C0C4CC**。选中日期后显示日期值，颜色 **#606266**；重置后恢复默认提示。
* **文字与对齐**：提示文字和已选值均为 **14px、常规字重**，在 **40px** 控件内垂直居中；左右内边距、边框和圆角沿用表单组件规范，不因筛选字段单独改变。
* **原型兼容**：如原生日期输入在浏览器中显示本地化默认格式或深色日历图标，需隐藏其原生展示并以以上占位文字和 ElementUI 图标呈现；日期选择功能仍须可用。不得以已选中的假值代替占位提示。

    * **查询按钮**：`type="primary"`，绑定 `icon="el-icon-search"`，高度 40px，文字居中。
    * **重置按钮**：不传 `type`，绑定 `icon="el-icon-refresh"`，高度 40px，文字居中。

## 3. 业务操作区（Business Actions）
* **批量操作**：如“批量入库”，采用 `danger` 类型（红色）以突出提示风险。
* **功能工具**：如“导出”，采用 `primary` 浅色风格，文字为白色。

---

## 4. 交互逻辑
* **Tab 切换**：点击不同 Tab，应触发接口重新请求对应状态的数据。
* **查询触发**：点击”查询”按钮后执行检索；回车键应绑定查询事件。
* **重置行为**：点击”重置”需恢复所有下拉菜单至默认值，清空所有输入框内容。

---

## 5. Tab 联动逻辑（筛选条件驱动 Tab 动态显示）

当页面存在影响 Tab 可见性的筛选条件时，Tab 列表需根据筛选值**动态显示/隐藏**。

### 规则定义
* **联动触发时机**：影响 Tab 的筛选项值发生变化时，立即重新计算可见 Tab 列表，无需点击查询。
* **自动回退规则**：若筛选条件变化导致当前激活的 Tab 被隐藏，系统自动将激活 Tab 回退至列表第一项（通常为默认状态 Tab），同时重置分页至第 1 页。
* **重置还原**：点击「重置」按钮后，筛选条件清空，Tab 列表恢复完整显示。

<!-- #AI:design:start -->
### 子模块联动实现

筛选值、展示 Tab 和默认回退 Tab 的具体枚举由页面业务说明或已确认 PRD 确认；公共规范统一约束“筛选变化 → 重新计算可见 Tab → 必要时回退并重置分页”的流程。

### Vue 2 实现示例

```javascript
computed: {
  // 根据筛选条件计算可见 Tab，具体枚举由页面业务说明提供
  visibleTabs() {
    const src = this.filters.source
    if (!src) return ALL_TABS
    return getVisibleTabsByFilter(src)
  }
},
methods: {
  // 筛选来源变化时：检查当前 Tab 是否仍可见，否则自动回退
  handleSourceChange() {
    this.currentPage = 1
    const names = this.visibleTabs.map(t => t.name)
    if (!names.includes(this.activeTab)) this.activeTab = names[0]
  }
}
```
