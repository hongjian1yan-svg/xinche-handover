## 从这里开始

本包适用于信车 PC 管理后台，先阅读 [规范索引](公共规范/INDEX.md)，再按实际页面选读正文。花乡、APP、小程序和鸿源市场 C 端官网使用各自规范。

本包包含：

- 9 份公共规范：全局视觉、页面整体布局、侧边栏、Tab 筛选、按钮、表单、表格、标签、弹窗与抽屉。
- 3 份业务说明：冻结车管理、资金渠道管理、金融初始化；仅适用于各自业务模块。
- 规范索引、本说明和来源清单。Markdown 文档可在支持 Markdown 的编辑器中阅读，文件之间使用包内相对链接。

本包是现有文档的整理副本。公共规范正文保留原文，业务说明仅调整回链；没有合并或新增设计规则。
